## 使用方式

这些文件是仓库中的源资料，不会因为放入本目录就自动写入知识库。启动应用后，进入“资料管理”页面并点击“导入系统资料”。系统会自动检查已导入、缺失、失败和版本变化的资料，依次完成解析、分块、Embedding 和索引建立。

手动选择 documents/ 下的文件上传仅用于开发和调试。

待资料状态变为“成功”后，才会进入问答、评测和检索实验。

## 维护约定

- 只提交已获授权或可公开使用的资料，不要放入密钥、个人隐私或运行时数据库文件。
- 修改资料时保留清晰的文件名，并在提交说明中记录来源、发布日期或版本变化。
- data/、uploads/ 和 FAISS 索引属于运行时数据，不放在本目录中。
