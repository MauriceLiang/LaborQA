## 建议的生产恢复顺序

实际部署前，按[部署 README](../../../deploy/README.md) 操作：确认当前 commit、备份 `data/` 和 `uploads/`、校验 Compose/Caddy 配置，再执行部署。不要使用 `docker compose down -v`，避免删除 Caddy 证书卷。数据库迁移后的回滚必须同时考虑代码版本与数据备份，不能只切换代码。

本轮临时环境停机时，可停止本地 Uvicorn 与 Vite 进程；原始项目运行数据不受影响。评测原始结果会在临时数据库移除前以脱敏 JSON 导出到本目录 `assets/`。
