# 检索策略对照实验

> 状态：已完成；正式实验 ID：`1`。<br>
> 实验只使用隔离候选数据与实验索引，不替换生产索引。

## 设计

- A：系统内置 `基线 A · 平衡`，默认分块大小 600、overlap 100、Top K=5、相似度阈值 0.35。
- B：系统内置 `基线 B · 小分块`，分块大小 400、overlap 100；其他检索参数与 A 保持一致。唯一计划变量为 chunk size。
- 相同条件：同一 10 份资料 / 705 个原始 Chunk 集合、本地 BGE Embedding、DeepSeek Flash、balanced、plain 风格，候选 K=20、轻量重排开。
- 测试集：固定选择 10 题，ID 为 `4, 9, 17, 32, 33, 36, 38, 43, 45, 60`。样本包含完整 Baseline 中 4 个自动判分失败样例、2 个其他应答案例、2 个多轮案例和 3 个应拒答案例。
- 输出：同一用例在两组的答案判分、拒答、来源命中、多轮结果和检索耗时；通过实验运行 ID 追溯逐题数据。
- 其余条件：同一隔离知识库原始资料、同一 BGE 向量模型、DeepSeek Flash、balanced、plain、Candidate K=20、Top K=5、阈值 0.35、轻量重排开启、完整 CrossEncoder 关闭。

## 结果

| 指标 | A：600 / 100 | B：400 / 100 |
| --- | ---: | ---: |
| 题次完成 | 10/10 | 10/10 |
| 应答判分 | **6/7（85.71%）** | **4/7（57.14%）** |
| 应拒答正确 | **3/3（100%）** | **3/3（100%）** |
| 来源命中 | **7/7（100%）** | **7/7（100%）** |
| 平均检索阶段耗时 | **189.9 ms** | **234.4 ms** |
| 最大单题检索阶段耗时 | 699 ms | 610 ms |

两组共 20/20 题次完成。批次数据库时间戳 01:19:20–01:23:32，差值 4 分 12 秒（无时区字段）。平均检索时间按每题各轮检索耗时合计计算，不包含模型改写、回答生成或自动判分耗时。

### 差异样例

- A 的唯一判分失败是多轮用例 #36：结果标记 `correct=0`、`refused=0`，即系统没有正式拒答，但回答仍未覆盖“欠薪解除与经济补偿”的核心要点。
- B 另外在 #4（工作地点变更）和 #17（年休假）判分失败；#36 发生拒答，尽管该用例要求应答。
- 3 个应拒答案例在两组都正确拒答；两组来源命中均为 7/7。
- 与完整 60 题 Baseline 相比，同一个 LLM 在不同批次对 #4、#17 的答案判定不同，显示模型生成和 LLM 判分存在运行间波动。

### 结论

本轮 10 题的偏差集中样本中，400 字符小分块没有改善回答判分或来源命中，平均检索还多 44.5 ms（约 23.4%）。本次不建议为考核演示切换到 B；继续使用 A（600/100）。这只是小样本策略验证，不足以证明 A 对所有劳动问题普遍更好。
